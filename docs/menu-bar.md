# 菜单栏显示

macOS 的菜单栏可以显示当前服务商的图标和一个数值。打开服务商详情时，菜单栏会跟随该服务商；回到总览或设置页后，继续显示上次选中的服务商。

- 有可用配额时，显示真实的剩余或已用百分比，具体取决于设置中的显示方式。
- 没有配额百分比，但有余额时，DeepSeek、Moonshot、OpenRouter 和 xAI 显示服务商返回的余额及货币符号。DeepSeek 同时有人民币和美元余额时，优先显示有余额的人民币，其次是美元；详情页仍显示两种货币。
- 刷新尚未完成或没有可用数值时，只显示服务商图标，不显示 `--%`。

OpenRouter 只有在 API Key 设置了有效限额时才显示该限额的百分比；否则显示账户余额。账户的累计 Credits 不是一个会重置的配额，不用于菜单栏百分比。余额为零时仍显示 `$0.00`。

菜单栏的柱形和圆环样式仍用于显示有配额比例的服务商。Windows 首版使用静态系统托盘图标，不显示动态标题。
